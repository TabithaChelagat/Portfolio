Deploy on Vercel:
1. Put this whole folder (index.html, styles.css, assets/) in a GitHub repo, or drag the folder into vercel.com/new.
2. Framework Preset: Other. Build command: none. Output directory: ./ (root).
3. Deploy, then add your own domain later if you want.
Edit projects in the P list at the bottom of index.html. Thumbnails live in assets/thumbs/<slug>.png.
